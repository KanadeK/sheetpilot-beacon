# Synthetic example workbooks

These `.xlsx` files are generated by `python scripts/generate_samples.py` and
licensed under the repository's MIT License. They contain fictional names,
fixed synthetic values, and no external data.

Each workbook contains five documented audit findings. The machine-readable
contract is in `expected_findings.json`.

- `budget_model.xlsx`: budget planning with a hidden adjustment dependency.
- `sales_forecast.xlsx`: sales planning with an external-workbook formula.
- `engineering_boq.xlsx`: bill-of-quantities calculations with a hidden rate.

The workbooks intentionally contain broken or fragile formulas and are not
templates for production decisions.
