# SheetPilot Beacon

[![CI](https://github.com/KanadeK/sheetpilot-beacon/actions/workflows/ci.yml/badge.svg)](https://github.com/KanadeK/sheetpilot-beacon/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-0f766e.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/KanadeK/sheetpilot-beacon)](https://github.com/KanadeK/sheetpilot-beacon/releases)

SheetPilot Beacon is an offline audit tool for fragile Excel formulas, hidden
dependencies, hardcoded constants, anomalous cells, and business-rule drift.
It is designed for finance, operations, cost engineering, consulting, and data
teams that need evidence without uploading workbooks or changing the originals.

The public-repository sample scan found no active project with both the same
name and a highly isomorphic feature set. See
[the competitor scan](docs/COMPETITOR_SCAN.md) for the bounded methodology and
the project's differentiation.

## Status

Version `v0.1.0` is the first public contract. The package targets Python 3.12
and keeps workbook analysis local.

## Development setup

```bash
python -m pip install -e ".[dev]"
python scripts/verify.py
```

The completed user workflows, sample workbooks, screenshots, CLI commands, and
security boundaries are documented in this README as their implementation
milestones land.
